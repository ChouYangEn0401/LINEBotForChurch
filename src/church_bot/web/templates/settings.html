① 服事表從哪裡來
先在 Google Sheet 點開你要的「分頁」，再從瀏覽器網址列複製整串。公開連結模式要先到右上角「共用」→ 一般存取權改成「知道連結的使用者」。
留空 = 用網址裡的那個分頁。服務帳號模式可以填多個（用逗號隔開），或填 * 代表全部分頁一起讀。
只有來源選「本機 CSV 檔」才會用到。預設是範例服事表 config/roster.demo.csv。
只有「服務帳號」模式才會用到，步驟見 docs/SETUP_GOOGLE.md。
通常選「自動判斷」就好。三種排法的圖解見「說明」。
② 什麼時候自動發送
建議在聚會前幾天，例如星期四晚上 8 點（發送當下才讀服事表，一定是最新的）。電腦要開著才會發送。雙擊過 weekly-on.bat 的話，不用開著這個程式，Windows 會在背景發；沒有的話，這個程式要在執行才會發。剛好關機錯過，12 小時內開機會自動補發。
1 = 每週發送（預設）。改成 2 大約可以省一半的 LINE 則數（見 docs/LINE_PRICING.md）—— 但請記得同時把下面「往後看幾天」改成至少 每幾週 × 7 天，不然中間那一週的服事不會出現在提醒裡； 設定錯的話系統會提醒你。
台灣請用 Asia/Taipei，不用改。
③ 訊息長什麼樣子
%-m = 月、%-d = 日、%Y = 西元年、{roc_year} = 民國年、{weekday} = 週日、{weekday_long} = 星期日。例如「%-m/%-d（{weekday}）」→ 9/13（週日）
例如「講員、司會、敬拜、司琴」。寫部分字也可以。
可用：{{ "{{ title }}" }} 標題、{{ "{{ date_text }}" }} 日期、{{ "{{ label }}" }} 聚會、{{ "{{ note }}" }} 備註、{{ "{{ footer }}" }} 結尾； 服事清單用 {{ "{% for a in assignments %}" }}…{{ "{{ a.role }}" }}：{{ "{{ a.names }}" }}…{{ "{% endfor %}" }}。改壞了按「恢復預設模板」就好。
④ 出問題時通知誰
服事表沒更新、名字對不到、LINE 送不出去…都會通知這個人。先加機器人好友，再私訊它「/我的ID」就能拿到。 建議填個人：通知群組的話每次都會按群組人數扣 LINE 額度。
⑤ LINE 聊天室指令

大家在群組或私訊機器人打「/」開頭的指令（例如 /我的ID）。需要設定 Webhook 才會有反應，見「說明」。

登記後要到「同工名單 → LINE 帳號」確認才會生效。平常建議關著，要收集時再打開，避免有人亂填。
每次修改都要輸入一次性驗證碼（6 位數、5 分鐘有效、錯 3 次作廢）。能改的只有「收集名單」「自動發送」「每幾週」， LINE 金鑰、密碼、管理員永遠不能從聊天室改。有人正在等驗證時，這個網頁最上面也會出現「核准／拒絕」按鈕。
每次私訊算 1 則（管理員填群組的話按人數算），每天最多 10 次，超過就只顯示在視窗上，不會被有心人拿來耗光額度。
⑥ 進階
還沒申請好 LINE 時，可以先選「測試模式」把整個流程跑一遍。
發送時提醒「今天起幾天內」的聚會。每週提醒一次就填 7；每兩週發送一次就要填 14 以上。
服事表排到的最後一天，距離今天少於這個天數，就提醒管理員「該排下一期了」。

🔑 LINE 金鑰與網頁密碼

這些是機密，只存在這台電腦的 .env 檔案，不會上傳到 git。已經設定過的欄位留空就不會改變。

LINE Developers → 你的 Channel →「Messaging API」分頁最下面 → Channel access token (long-lived) → Issue。
「Basic settings」分頁。只有要用「在群組打 /群組ID 自動抓」功能才需要。
設定後，打開網頁的任何一頁都會先看到登入畫面，要填這個密碼才能繼續；改密碼後，所有人（包含你自己）都要重新登入一次。
