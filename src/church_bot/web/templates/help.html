每一頁是做什麼的

頁面什麼時候來這裡
🏠 主控台看現在正不正常、有沒有要處理的事、這週會發什麼；臨時想提早發或重發。
📄 服事表看 Google Sheet 的內容和程式讀到的結果、打開 Google Sheet 去改、第一次接上服事表。

📜 發送紀錄以前每一次發了什麼、有沒有失敗。
⚙️ 設定 管理員發送時間、訊息樣子、通知誰、LINE 金鑰與網頁密碼。打開左下角「管理員模式」才會出現在選單。

「管理員模式」只是把進階的東西收起來，讓平常的畫面簡單一點；它不是權限。要限制誰能打開這個網頁，請到「設定 → 金鑰與密碼」設網頁密碼。

平常要做什麼

什麼都不用做。只要照常更新 Google Sheet 上的服事表就好。到了排程時間會自動發送。

覺得怪怪的系統檢查

第一次設定（管理員，照順序做）

  1. 申請 LINE 機器人：照 docs/SETUP_LINE.md 做，拿到 Channel access token，貼到「設定 → 🔑 金鑰與密碼」。
  2. 接上服事表：Google Sheet 右上「共用」→ 改成「知道連結的使用者可以檢視」，複製網址，到「服事表」頁貼上、按「接上」。
  3. 把機器人邀進 LINE 群組：在群組打 /群組ID，到「LINE 群組」新增群組、貼上 ID，按「送測試訊息」確認收得到。
  4. 設定管理員：私訊機器人 /我的ID，把拿到的 ID 填到「設定 → 🔔 通知」，出問題才找得到你。
  5. 排每週的發送：在 Telegram 機器人加每週四 20:00 的排程呼叫 cli.bat send（見 README）；或到「設定 → ⏰ 發送時間」開啟內建排程並讓程式一直開著。
  6. 按「系統檢查」，全部 ✅ 就完成了！回主控台看這週的預覽。

在 LINE 可以打的指令

指令都用「/」開頭（全形「／」也可以），一般聊天機器人一律不回應。這些回覆都不計入 LINE 每月額度。 群組裡打 /權限 會列出誰是管理員、哪個指令誰能用。

/提醒🆓 誰都可以打。立刻把這週的提醒回在這個群組（免費）。排程前 2 天內打過、內容沒變，排程就自動略過，不會重複扣費。
/群組ID回覆這個群組的 ID（新增 LINE 群組時用）。
/我的ID回覆你自己的 ID（設定管理員時用）。
/我的名字 王小明登記自己的真實姓名，管理員在「同工名單 → LINE 帳號」確認後就對得上服事表。要管理員先「開放登記」。
/我的暱稱 阿明多登記一個稱呼（不會蓋掉真實姓名，最多 5 個）。管理員按「加成其他寫法」後，服事表寫這個也對得到。
/權限
/我的權限		誰是管理員、哪個指令誰能用；/我的權限 是打的人自己的狀況（有沒有對應到同工、@ 得到嗎）。
/別周測試 1004👑 只有管理員。試印「10/4 起這一週」的提醒，只回在你打指令的聊天室，不寫紀錄、不影響排程。
/設定列出可以用 LINE 改的設定。例如 /設定 收集名單=開，會要一次性驗證碼（私訊管理員＋顯示在電腦上），再打 /驗證 123456 才生效。網頁最上面也能直接「核准／拒絕」。
/說明列出這些指令（/help、/? 也可以）。

服事表可以怎麼排

三種常見排法都認得（設定選「自動判斷」就好）。表頭有「日期」兩個字最保險。

  • 一格多人：用 、 , / 或換行隔開都可以。
  • 沒有人：留空，或寫 -、無、休。
  • 日期寫法：2026/9/13、9/13、9月13日、115/9/13（民國）都可以。
  • 要寫備註：加一欄「備註」，例如「聖餐主日」，會出現在提醒裡。
  • 一天兩場聚會：加一欄「聚會」，同一個日期寫兩列；LINE 群組可以設定「只發這些聚會」。

到「服事表」頁可以直接看到程式怎麼讀你現在這張表：哪一列是表頭、哪幾列讀到日期。

常見狀況

主控台說「某某在同工名單找不到」

服事表上出現了新名字或打錯字。訊息還是會照原樣送出，不影響提醒。到「同工名單」最上面的「名字對不到」，選「新同工」或「就是某某」按確定就好。

想一次收集大家的真實姓名和 LINE 帳號

到「同工名單 → LINE 帳號」按「開放登記」，請大家在群組打「/我的名字 真實姓名」。登記的人會出現在同一張表，按「對應」「加入」或「改名」確認。收集完記得按「關閉登記」。

有人改了 LINE 名稱

不用處理。對應靠的是永遠不變的 LINE ID，不是 LINE 名稱。

有人離開教會 / 不再服事

到「同工名單」把他編輯成「停用」（比刪除好）。之後如果服事表不小心又排到他，會提醒管理員。

新的群組、群組換了

把機器人邀進新群組，它會自動出現在「LINE 群組」頁，按「加入」再勾「啟用」。舊群組不用了就改成停用或刪除。同工名單和 LINE 帳號跟群組無關，換群組不用重新收集。

服事表排到下一季、開了新分頁

最簡單：直接在同一個分頁往下加。如果開了新分頁，到「服事表」→「換成別的 Google Sheet」貼新分頁的網址。服事表快用完時（預設剩 14 天），會先提醒管理員。

「這個月的 LINE 訊息額度用完了」

LINE 免費方案每月 200 則，推播到群組是按群組人數算。詳見 docs/LINE_PRICING.md。省錢的方法：讓大家在群組打 /提醒（免費），排程就會自動略過。

「LINE token 錯誤或已失效」

到 LINE Developers 重新發行 Channel access token，貼到「設定 → 🔑 金鑰與密碼」。

在群組打「/群組ID」機器人沒反應

聊天指令、自動收集 LINE 帳號都需要開著 Webhook（雙擊 3-open-webhook.bat，見 docs/SETUP_LINE.md）。每週提醒本身完全不需要 Webhook。

電腦關機 / 睡眠會怎樣

由 Telegram 排程的話，只要 Telegram 機器人那台開著就會發。用內建排程的話，關機時不會發送；錯過時間後 12 小時內打開程式會自動補發（已經送過的不會重送）。
