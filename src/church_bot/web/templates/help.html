覺得怪怪的系統檢查
第一次設定管理員照順序做一次
  1. 申請 LINE 機器人：照 docs/SETUP_LINE.md 拿到 Channel access token，貼到「設定 → 金鑰與密碼」。
  2. 接上服事表：Google Sheet 開成「知道連結的使用者可以檢視」，到 服事表 → 換一份服事表 貼網址。
  3. 加群組：把機器人邀進 LINE 群組，在群組打 /群組ID，到 LINE 群組 新增並貼上 ID，按「送測試訊息」。
  4. 設定管理員：在群組打 /我的名字 你的名字，到 LINE 帳號 按「對應到」，再按「設為管理員」。出問題就會通知你，也才能用 /別周測試。
  5. 打開自動發送：「設定 → 什麼時候發」勾「自動發送」、選星期幾和幾點。後台（2-start）開著就會照時間發；想多一層保險，可以讓 Telegram 每週呼叫 cli.bat send（今天輪到的牧區才會發，見 README）。
  6. 系統檢查：全部通過就完成了。
在 LINE 可以打的指令都用「/」開頭；這些回覆不扣 LINE 額度
/提醒誰都能打。把這週的提醒回在這個群組。排程前 2 天內打過、內容沒變，排程就略過。
/群組ID回這個群組的 ID（新增 LINE 群組時用）。
/我的ID回你自己的 ID（設定管理員時用）。
/服務網址回這個管理網頁現在的網址。免費模式每次重開網址都會變， 換了之後不用貼給每位管理員，請他們自己問機器人。還沒設密碼時只回給管理員。
/我的名字 王小明登記真實姓名，等管理員到「LINE 帳號」確認。要先開放登記。
/我的暱稱 阿明多登記一個稱呼，最多 5 個，不會蓋掉真實姓名。
/權限 /我的權限誰是管理員、哪個指令誰能用；自己有沒有對應到同工。
/別周測試 1004只有管理員。試印 10/4 那一週的提醒，只回在打指令的地方，不寫紀錄。
/設定用 LINE 改少數設定。每次都要驗證碼，再打 /驗證 123456 才生效。
/說明列出這些指令。

常見狀況
主控台說「某某在同工名單找不到」

服事表出現了新名字或打錯字。訊息照原樣送出，不影響提醒。到 同工名單 最上面選他是誰。

想一次收集大家的真實姓名和 LINE 帳號

到 LINE 帳號 按「開放登記」，請大家在群組打「/我的名字 真實姓名」，再逐一確認。收集完按「關閉登記」。

誰是管理員？怎麼多加一位

管理員 = 同工名單裡勾了「管理員」而且對應好 LINE 帳號的人。到 LINE 帳號 找到那個人，按「設為管理員」；或在 同工名單 編輯他，勾「管理員」。管理員可以用 /別周測試、會拿到 /設定 的驗證碼、出問題會收到通知。能開這個網頁的人就能勾，所以要限制的話請設網頁密碼。

有人改了 LINE 名稱

不用處理。對應靠的是不會變的 LINE ID。

有人離開教會、不再服事

到同工名單把他改成「停用」，比刪除好：之後服事表又排到他，會提醒管理員。

新的群組、群組換了

把機器人邀進新群組，它會出現在 LINE 群組 最上面，按「加入」再勾「要收到提醒」。

服事表排到下一季、開了新分頁

直接在同一個分頁往下加最簡單。開了新分頁就到 服事表 → 換一份服事表 貼新分頁的網址。

這個月的 LINE 額度用完了

免費方案每月 200 則，送到群組按人數算。讓大家在群組打 /提醒（免費），排程就會略過。詳見 docs/LINE_PRICING.md。

在群組打指令，機器人沒反應

聊天指令要開著免費模式（雙擊 3-open-webhook.bat）。每週提醒不需要它。

電腦關機會怎樣

自動發送要後台開著才會發；錯過時間後 12 小時內打開程式會補發。有設 Telegram 備援的話，Telegram 那台開著就會發（不會發兩次）。
