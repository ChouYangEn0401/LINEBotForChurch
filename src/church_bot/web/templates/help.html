❓ 這個機器人在做什麼

每週固定時間，它會照順序做這四件事（首頁最上面的「運作流程」就是這四步現在的狀況）：

1. 📄 讀服事表Google Sheet 上這週誰服事什麼
→
2. 🙋 對名字綽號換成真實姓名、找出停用的人
→
3. 👥 送到群組每個 LINE 群組收自己需要的部分
→
4. 🚨 有問題就通知LINE 私訊管理員＋首頁變紅／黃

平常什麼都不用做：只要更新 Google Sheet 上的服事表就好。這台電腦開著、程式在跑，就會自動提醒。

🚀 第一次設定（照順序做）

  1. 申請 LINE 機器人：照 docs/SETUP_LINE.md 做，拿到 Channel access token，貼到「⚙️ 設定 → 🔑 金鑰與密碼」。
  2. 接上服事表：Google Sheet 右上「共用」→ 改成「知道連結的使用者可以檢視」，複製網址，貼到「⚙️ 設定 → ① 服事表」，來源選「Google Sheet（公開連結）」。
  3. 把機器人邀進 LINE 群組：機器人會自己說出群組 ID，也會自動出現在「👥 LINE 群組」頁（沒反應的話，看下面「沒有設定 Webhook 怎麼辦」）。
  4. 到「👥 LINE 群組」把群組勾「啟用」，按「測試」確認群組有收到。
  5. 私訊機器人 /我的ID，把拿到的 U 開頭 ID 填到「⚙️ 設定 → ④ 通知管理員」，出問題才找得到你。
  6. 按「🩺 系統檢查」，全部是 ✅ 就完成了！回首頁看看這週的預覽。

💬 在 LINE 可以打的指令

指令都要用「/」開頭（全形「／」也可以），一般聊天機器人一律不回應，不會吵到群組。這些回覆都不計入 LINE 每月額度。 權限只有兩層：大家都能用的指令最多只會「回一句話」或「記一個等管理員確認的名字」；會影響大家的（改設定、試印別週） 靠「驗證碼只給管理員」和「管理員 LINE ID」擋住。群組裡打 /權限 就會把這些印出來。

/群組ID回覆這個群組的 ID（填到 LINE 群組用）
/我的ID回覆你自己的 ID（填到設定就能收管理員通知）
/我的名字 王小明登記自己的真實姓名，管理員在「🙋 同工名單 → LINE 帳號」確認後就對得上服事表。 管理員要先按「開放登記」才能用；登記錯了再打一次就會蓋掉。
/我的暱稱 阿明多登記一個稱呼（不會蓋掉真實姓名，一個人最多 5 個）。 管理員在「🙋 同工名單 → LINE 帳號」按「加成其他寫法」後，服事表寫這個稱呼也對得到同一個人。
/權限
/我的權限		 誰是管理員、哪個指令誰能用、機器人不會做什麼；/我的權限 是打的人自己的狀況 （有沒有對應到同工、@ 得不到就會告訴他怎麼登記）。
/別周測試 1004👑 只有管理員能用。試印「10/4 起這一週」的提醒 （10/04、10月4日、2026/10/4 都可以）：只回在你打指令的那個聊天室， 不會發到其他群組、不寫紀錄、也不影響每週的自動提醒。想安靜測就私訊機器人打。
/設定列出可以用 LINE 修改的設定（收集名單、自動發送、每幾週）。 例如 /設定 收集名單=開：機器人會把一次性驗證碼私訊給管理員並顯示在執行程式的視窗， 再打 /驗證 123456（或直接打 6 個數字）才會生效；/取消 可以取消。 等驗證的時候，這個管理網頁最上面也可以直接按「核准／拒絕」。
/提醒🆓 誰都可以打（只在「LINE 群組」頁啟用的群組有效）。立刻用「回覆」免費送出這週的提醒—— 跟首頁的「📤 立刻發送」效果一樣，但那顆按鈕是 Push（會計費），這個指令不會。 排程時間前 2 天內打過、內容也一樣，排程就自動略過，不會重複扣費（更早打的不算，排程照常送）；服事表改過才會再送新的。舊的「/現在提醒」也還能用。
/說明列出這些指令（/help、/? 也可以）

🤔 常見狀況

首頁說「某某在同工名單找不到」

服事表上出現了新名字或打錯字。訊息還是會照原樣送出，不影響提醒。到「🙋 同工名單」最上面的「待處理」，選「新增成新同工」或「是某某的其他寫法」按確定就好。

想一次收集大家的真實姓名和 LINE 帳號

到「🙋 同工名單 → LINE 帳號」按「開放登記」，請大家在群組打「/我的名字 真實姓名」。登記的人會出現在同一張表，按「對應」「加入」或「改名」確認。收集完記得按「關閉登記」。

有人改了 LINE 名稱

不用處理。對應靠的是永遠不變的 LINE ID，不是 LINE 名稱；機器人每天最多更新一次顯示名稱，只是讓你看得出是誰。

有人離開教會 / 不再服事

到「🙋 同工名單」把他編輯成「停用」。之後如果服事表不小心又排到他，會提醒管理員。

新的群組、群組換了

把機器人邀進新群組，它會自動出現在「👥 LINE 群組」頁，勾「啟用」就好。舊群組不用了就改成停用或刪除。同工名單和 LINE 帳號跟群組無關，換群組不用重新收集。機器人被踢出群組時，會通知管理員。

服事表排到下一季、開了新分頁

最簡單：直接在同一個分頁往下加。如果開了新分頁，要到「⚙️ 設定」把網址換成新分頁的網址。服事表快用完時（預設剩 14 天），會先提醒管理員。

「這個月的 LINE 訊息額度用完了」

LINE 免費方案每月 200 則，推播到群組是按群組人數算。詳見 docs/LINE_PRICING.md（有報帳需要的資訊）。

「LINE token 錯誤或已失效」

到 LINE Developers 重新發行 Channel access token，貼到「⚙️ 設定 → 🔑 金鑰與密碼」。

在群組打「/群組ID」機器人沒反應（沒有設定 Webhook 怎麼辦）

聊天指令、自動收集 LINE 帳號都需要設定 Webhook（見 docs/SETUP_LINE.md 第 5 步）。只是要拿群組 ID 的話，拿到之後就可以關掉；要持續收集名字或用 LINE 改設定，Webhook 就要一直開著。每週提醒本身完全不需要 Webhook。

電腦關機 / 睡眠會怎樣

關機時不會發送。如果錯過排程時間，12 小時內打開程式會自動補發（已經送過的不會重送）。建議用「開機自動啟動」（見 README）。
