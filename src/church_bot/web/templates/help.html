❓ 這個機器人在做什麼

每週固定時間，它會：

  1. 📄 讀 Google Sheet 上的服事表，找出這週的聚會
  2. 🙋 用人員表把名字整理好（綽號換成正式名字、檢查有沒有人已經停用）
  3. 👥 依照群組表，把提醒送到每個 LINE 群組
  4. 🚨 有任何問題（服事表沒更新、名字對不到、LINE 送不出去），通知管理員，也會顯示在首頁

平常什麼都不用做：只要更新 Google Sheet 上的服事表就好，這台電腦開著、程式在跑，就會自動提醒。

🚀 第一次設定（照順序做）

  1. 申請 LINE 機器人：照 docs/SETUP_LINE.md 做，拿到 Channel access token，貼到「⚙️ 設定 → LINE 金鑰」。
  2. 接上服事表：Google Sheet 右上「共用」→ 改成「知道連結的使用者可以檢視」，複製網址，貼到「⚙️ 設定 → ① 服事表從哪裡來」，來源選「Google Sheet（公開連結）」。
  3. 把機器人邀進 LINE 群組，在群組打 群組ID，機器人會回覆一串 C 開頭的 ID（沒回覆的話，看下面「沒有設定 Webhook 怎麼辦」）。
  4. 到「👥 群組」頁新增群組，貼上 ID、勾「啟用」，按「測試」確認群組有收到。
  5. 私訊機器人 我的ID，把拿到的 U 開頭 ID 填到「⚙️ 設定 → ④ 管理員 LINE ID」，出問題才找得到你。
  6. 到「🩺 系統檢查」，全部是 ✅ 就完成了！回首頁看看這週的預覽。

📋 服事表可以怎麼排

三種常見排法都認得（設定選「自動判斷」就好）。表頭有「日期」兩個字最保險。

  • 一格多人：用 、 , / 或換行隔開都可以。
  • 沒有人：留空，或寫 -、無、休。
  • 日期寫法：2026/9/13、9/13、9月13日、115/9/13（民國）都可以。
  • 要寫備註：加一欄「備註」，例如「聖餐主日」，會出現在提醒裡。

🤔 常見狀況

首頁說「某某在人員表找不到」

服事表上出現了新名字或打錯字。訊息還是會照原樣送出，不影響提醒。到「🙋 人員」頁，會列出所有找不到的名字，選「新增成新同工」或「是某某的其他寫法」按確定就好。

有人離開教會 / 不再服事

到「🙋 人員」頁把他編輯成「停用」。之後如果服事表不小心又排到他，會提醒管理員。

新的群組、群組換了

把機器人邀進新群組，在群組打「群組ID」，到「👥 群組」頁新增或修改 LINE_ID。舊群組不用了就改成停用或刪除。機器人被踢出群組時，會通知管理員。

服事表排到下一季、開了新分頁

最簡單：直接在同一個分頁往下加。如果開了新分頁，要到「⚙️ 設定」把網址換成新分頁的網址。服事表快用完時（預設剩 14 天），會先提醒管理員。

「這個月的 LINE 訊息額度用完了」

LINE 免費方案每月 200 則，推播到群組是按群組人數算。詳見 docs/LINE_PRICING.md（有報帳需要的資訊）。

「LINE token 錯誤或已失效」

到 LINE Developers 重新發行 Channel access token，貼到「⚙️ 設定 → LINE 金鑰」。

在群組打「群組ID」機器人沒反應（沒有設定 Webhook 怎麼辦）

「群組ID」指令需要設定 Webhook（見 docs/SETUP_LINE.md 第 5 步）。只有第一次拿 ID 時需要，拿到之後就可以關掉。

電腦關機 / 睡眠會怎樣

關機時不會發送。如果錯過排程時間，12 小時內打開程式會自動補發（已經送過的不會重送）。建議用「開機自動啟動」（見 README）。

💬 在 LINE 可以打的指令

群組ID機器人回覆這個群組的 ID（填到群組表用）
我的ID機器人回覆你自己的 ID（填到人員表才能 @ 你；填到設定可以收管理員通知）

這些回覆不會計入 LINE 每月額度。其他聊天內容機器人一律不回應，不會吵到群組。
