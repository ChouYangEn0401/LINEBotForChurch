# ⛪ 教會服事表 LINE 自動提醒機器人

每週固定時間，自動讀 **Google Sheet 服事表**，把「這週誰服事什麼」發到 **LINE 群組**。
有任何問題（服事表沒更新、名字對不到、LINE 送不出去）都會**通知管理員**，不會默默失敗。

```
📣 本週服事提醒
📅 9/13（週日）・主日崇拜

▸ 講員：王大衛牧師
▸ 司會：吳恩典
▸ 敬拜主領：陳小明
▸ 司琴：林美華
▸ 招待：黃喜樂、吳恩典

📝 聖餐主日
謝謝大家的擺上 🙏
```

## 它會幫你做什麼

- ⛪ **很多個牧區一起用**：首頁列出所有牧區（青年牧區、壯年牧區…），點進去就是那個牧區自己的服事表、同工名單、LINE 群組、發送時間和訊息，各自獨立、互不影響；要幫別的牧區建，回首頁再新增一個。見 [docs/MINISTRIES.md](docs/MINISTRIES.md)。
- 📄 **讀服事表**：直接讀 Google Sheet；三種常見排法都認得，日期寫法（9/13、9月13日、115/9/13…）也很寬鬆。
- 👥 **分群組發送**：例如「敬拜團」群組只收敬拜相關的服事；**每個群組可以有自己的提醒訊息**（標題、結尾，或整則改寫）。
- ✍️ **罐頭訊息不用懂程式**：直接打字，要放資料的地方點一下插入【標題】【日期】【服事名單】這類中文標籤，右邊馬上看到群組會收到的樣子。
- 🙋 **整理名字**：服事表寫綽號，訊息顯示正式名字（同一個人可以有很多個寫法：暱稱、英文名、LINE 舊名稱）；名字對不到會猜「可能是誰」；已經停用的人又被排到會提醒。
- 🎸 **小團**：敬拜團用組合式（整個小團一起上）時，服事表那一格只要寫團名，提醒會自動列出「晨光實體團（張晨光、陳小明、許心怡）」並 @ 團員。
- ⏰ **自動發送**：每個牧區照自己的「星期幾、幾點、每幾週」發；電腦剛好關機錯過，12 小時內打開程式會自動補發；同一次聚會不會重複發。
- 🕘 **變更紀錄**：設定、群組、名單每次修改都記下來（什麼時候、從哪裡、改了什麼），改錯了一鍵還原；直接用 Excel 改的也抓得到。
- 🚨 **出問題一定讓你知道**：管理網頁主控台顯示紅／黃色提醒，同時用 LINE 通知管理員。
- 📱 **收集 LINE 帳號**：大家在群組講話就記下 LINE ID；開放登記時打「/我的名字 王小明」（一步就好），
  管理員在群組打「/點名」就列出服事表上還沒登記的人，管理員一鍵對應到同工名單（換群組也不用重做）。
- 🔐 **用 LINE 改設定**：「/設定 收集名單=開」這類指令，每次都要一次性驗證碼（私訊管理員＋顯示在電腦上）。
- 💬 **在 LINE 問機器人**：`/提醒` 看這週誰服事、`/服務網址` 問管理網頁在哪裡、`/我的暱稱 阿明` 多登記一個稱呼、`/權限` 看誰能做什麼；管理員可以用 `/別周測試 1004` 先試印別一週的內容。
- 🖥️ **管理網頁**：不用改程式、不用打指令，用瀏覽器點一點就能設定。第一頁是**主控台**（正不正常、要處理什麼、這週會發什麼一眼看完），每一頁只做一件事，進階設定要按右上角「進階頁面」才會出現，沒有程式背景的同工也看得懂。
- 🔑 **三種身分**：網站密碼進來是訪客（看首頁、建牧區）；輸入牧區密碼才管得到那個牧區；伺服器管理員（另一組管理者密碼，從外面還要驗證器 App 或 Telegram 的 6 位數）什麼都能管，右上角還有「重新啟動」。

## 安裝（只要做一次）

### Windows

1. 安裝 Python：到 <https://www.python.org/downloads/> 下載安裝。**安裝的第一個畫面記得勾「Add python.exe to PATH」**。
2. 打開 `scripts\windows` 資料夾，**雙擊 `1-install.bat`**，等它跑完。
3. **雙擊 `2-start.bat`**，瀏覽器會自動打開管理網頁 <http://127.0.0.1:8787>。

> 如果跳出「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。

### Mac

1. 安裝 Python 3.11 以上：到 <https://www.python.org/downloads/macos/> 下載安裝。
2. 打開「終端機」（按 ⌘ + 空白鍵，搜尋「終端機」或 Terminal）。
3. 輸入 `bash`（後面打一個空格），把 `scripts/mac/1-install.sh` **拖進終端機視窗**，按 Enter。
4. 用同樣方法執行 `scripts/mac/2-start.sh`，瀏覽器會打開管理網頁 <http://127.0.0.1:8787>。

> `2-start` 是**管理網頁**（後台）。開著的時候，每個牧區照自己設定的時間自動發提醒。
> 不想讓電腦一直開著後台的話，也可以讓 Telegram 機器人每週呼叫一次 `cli.bat send` 當備援（見下面第 8 步），兩邊都觸發也只會發一次。
> 從舊版（只有一個牧區）升級：第一次打開新版會自動把原本的設定搬進「第一個牧區」，什麼都不用重設，到首頁改名字就好。

### 讓它自己活著：註冊成 Windows 服務（建議，Windows）

雙擊 `2-start.bat` 的缺點是那個黑色視窗一關、當掉、或電腦重開機，提醒就不會發了，而且**沒有人會知道**。
把它們註冊成 Windows 服務就沒有這個問題——跟 nginx 在 Windows 上的做法一樣。兩個程式各是一個服務：

| 程式 | 雙擊開（跟以前一樣） | 服務 | 服務名稱 |
|---|---|---|---|
| 後台（管理網頁＋每週提醒） | `2-start.bat` | `2-service-start` / `2-service-stop` / `2-service-restart` | `church-bot` |
| LINE 指令（臨時網址，群組打 `/提醒` 才會回） | `3-open-webhook.bat` | `3-service-start` / `3-service-stop` / `3-service-restart` | `church-bot-webhook` |

**雙擊 `scripts\windows\service\install.bat`**（會跳一次「是否允許變更你的裝置」，按「是」）。
兩個一起註冊；沒裝 cloudflared 的話只註冊後台。如果 2-start／3-open-webhook 的黑色視窗開著，它會請你先關掉。

跑完之後：

- 電腦**重新開機就自己起來**，不用登入 Windows、不用有人去點（LINE 指令會等後台起來才開）
- 程式**當掉 10 秒後自己再開一次**
- **右下角有兩個小圖示**：「後」＝後台、「令」＝LINE 指令。顏色就是狀態——
  綠＝服務在跑、藍＝雙擊開的在跑、黃＝正在啟動／停止、紅＝服務開著但程式不在（正在重開或一直起不來）、灰＝沒在跑。
  **右鍵**：結束程式（服務模式下 nssm 會在 10 秒後把它開回來）、服務：停止／啟動／重新啟動。
  在跑的變成不在、又不是你按的，會跳一個通知。登入 Windows 時自己出現；雙擊 2-start／3-open-webhook 時也會出現
- 停／開／重開**不用再跳 UAC**：install.bat 把這兩個服務的「啟動／停止／查詢」權限開給你的 Windows 帳號（只有這兩個）
- 這個資料夾裡的 `start.bat`、`stop.bat`、`restart.bat` 是兩個一起；`status.bat` 看服務狀態＋所有牧區的狀況；
  `uninstall.bat` 取消註冊（改回雙擊的用法，登入時開小圖示的捷徑也一起拿掉）
- `sc start church-bot`、`net stop church-bot-webhook`、「服務」管理員（`services.msc`）也都認得它們

> 小圖示每 5 秒在自己程式裡問一次 Windows「服務開著沒、那個程式還在不在」——不開新程式、不連網，一次不到 1 毫秒。
> 「結束程式」不是砍程式：它按一個 Windows 事件，程式收到後照 Ctrl+C 的路收工（「已關閉」照樣送到 Telegram）。

> 背後是 [nssm](https://nssm.cc)（公有領域的小工具，`install.bat` 第一次會自己用 winget 下載到 `tools\`）。
> Python 這種程式不會跟 Windows 的服務控制器對話，直接 `sc create` 會在啟動時卡住跳 error 1053，所以中間要包這一層。
>
> ⚠️ 服務在背景跑，**看不到黑色視窗，也不會跳出 `--popup` 的小提示**。
> 所以註冊成服務之後，狀態播報就是你的眼睛——開機、關機、當掉、每次發送都會傳一則到你的 Telegram。
> 想主動問：雙擊 `status.bat`，或在 Telegram 呼叫 `cli.bat 狀態 --telegram`。

### 狀態播報走 Notifier_TB（這個專案不保管 Telegram 金鑰）

這台電腦上已經有一支專門「把東西送到 Telegram」的機器人：**`Notifier_TB`**（跟本專案並排的資料夾）。
任何本地程式都可以推進去，`ISDStockProject` 的 live monitor 就是這樣用的，所以這裡照同一套走：

```
{"sig": <socket_secret>, "payload": <要送的文字>}   →  TCP 127.0.0.1:9999
```

要講話的時候才連一次、送完就關——**不連 api.telegram.org、沒有任何輪詢**。token、收件人、
訊息追蹤全部是 Notifier 的事，這個專案一個金鑰都不用保管。

- 預設自己去隔壁找 `../Notifier_TB/config.json`，所以通常**什麼都不用設定**
- Notifier 放在別的地方 → `.env` 填 `NOTIFIER_TB_HOME`
- 完全不想接 → `.env` 填 `NOTIFIER_DISABLED=1`
- Notifier 是「要用才開」的：**沒開著就幫它開**（跟 ClawBot 同一個做法：它自己的 `main.py --until-idle 180`，
  送完沒事做 3 分鐘自己關），所以 Notifier **不用**註冊成服務。後台以服務身分跑時，它是在看不到的桌面上被叫起來的，
  這時你自己雙擊 Notifier 的 `launcher.bat` 會說「已經有一個在跑」——等 3 分鐘它自己關掉再開就好
- 真的開不起來（例如 Notifier 的 `.venv` 不見了）時，訊息先存進 `data/notify_outbox.jsonl`，
  下次送得出去（或後台重開）時一起補送，不會不見

> `.env` 裡的 `TELEGRAM_BOT_TOKEN` 從此只跟「從外面登入伺服器管理員的一次性驗證碼」有關，跟播報無關。

## 第一次設定（跟著做，大約 30 分鐘）

安裝完一打開，首頁是**所有牧區**，已經有一個用**範例服事表**的「第一個牧區」，點進去主控台就能看到訊息長什麼樣子。接著：

> 🔰 第一次做、或想先確定不會出錯再動教會的群組？改看 **[docs/QUICKSTART_TEST.md](docs/QUICKSTART_TEST.md)**——
> 一樣的步驟，但會先教你只測試自己一個人，最後才接觸教會正式的群組。

0. **建牧區**：首頁把「第一個牧區」點進去，在「⚙️ 設定 → 這個牧區」改成你們的名字（例如青年牧區）；其他牧區回首頁按「＋ 新增牧區」。下面 2～7 步每個牧區各做一次。
1. **申請 LINE 機器人**（整個教會一次）：照 [docs/SETUP_LINE.md](docs/SETUP_LINE.md) 做，把拿到的 token 貼到首頁側欄「⚙️ 全教會設定 → 金鑰與密碼」（先按右上角「進階頁面」）。
   同一頁「伺服器管理員」設管理者密碼；想從外面登入管理者，再設驗證器 App 或 Telegram 登入碼（見 [docs/MINISTRIES.md](docs/MINISTRIES.md)「三種身分」）。
2. **接上服事表**：照 [docs/SETUP_GOOGLE.md](docs/SETUP_GOOGLE.md) 把 Google Sheet 開成「知道連結的人可以檢視」，網址貼到「📄 服事表」頁的「換成別的 Google Sheet」，按「接上」。服事表怎麼排見 [docs/SHEET_FORMAT.md](docs/SHEET_FORMAT.md)。
3. **設定群組**：把機器人邀進 LINE 群組，在群組打「/群組ID」，到「👥 LINE 群組」新增群組、貼上 ID，按「送測試訊息」確認收得到。
4. **設定管理員**：在群組打「/我的名字 你的名字」，到「🙋 同工名單 → LINE 帳號」按「對應到」，再按「設為管理員」。
   出問題會通知管理員，也只有管理員能用「/別周測試」「/點名」。可以勾好幾位。
5. **讓大家登記**（要 @ 人的話）：「同工名單 → LINE 帳號」按「開放登記」，管理員在每個群組打「/點名」，
   機器人會列出這個群組會提醒到、還沒登記的人，請他們打「/我的名字 他的名字」；再回「LINE 帳號」按
   「名字對得上的 N 位全部對應」。再打一次「/點名」看還剩誰，收集完記得「關閉登記」。
6. **系統檢查**：打開「❓ 說明 → 🩺 系統檢查」，全部 ✅ 就完成了！
7. **打開自動發送**：牧區的「⚙️ 設定 → 什麼時候發」勾「自動發送」，選星期幾、幾點。`2-start` 開著就會照時間發（`autostart-on.bat` 可以開機自動執行）。
8. **（選用）Telegram 備援**：Telegram 機器人每週呼叫下面這行，發「今天輪到的牧區」（自動發送開著、今天是它的發送日）；
   只想發某一個牧區就加 `--牧區 青年牧區`。重試、失敗跳視窗都包含在參數裡，跟後台同時觸發也只會發一次：

   ```
   C:\Users\user\Documents\LINEBotForChurch\scripts\windows\cli.bat send --retries 3 --retry-wait 300 --popup
   ```

**什麼都不用做。** 只要照常更新 Google Sheet 上的服事表就好。

|---|---|
| 看每個牧區正不正常、新增牧區、把新群組分到牧區 | ⛪ 首頁（所有牧區） |
| 看正不正常、有沒有要處理的事、這週會發什麼 | 點進牧區 → 🎯 主控台 |
| 臨時想提早發、服事表改了想重發 | 🏠 主控台 →「這次會發送」右邊的「立刻發送」 |
| 看 Google Sheet 的內容、程式讀到什麼、換一份服事表 | 📄 服事表 |
| 新增群組、群組換了、某個群組要不一樣的提醒訊息 | 👥 LINE 群組（編輯群組 →「這個群組的提醒訊息」） |
| 新同工、有人離開、名字對不到 | 🙋 同工名單 |
| 有人在 LINE 登記了名字要確認、整團一起上的小團 | 🙋 同工名單 → 📱 LINE 帳號／🎸 小團 |
| 改發送時間、訊息長相 | ⚙️ 設定（先按右上角「進階頁面」，側欄才有「設定」） |

| LINE 金鑰、網站密碼、管理者密碼、驗證器 App | 首頁 → ⚙️ 全教會設定（伺服器管理員） |
| 更新過程式、覺得怪怪的 | 右上角「重新啟動」（伺服器管理員），大約 5 秒 |
| 看以前發了什麼、有沒有失敗 | 📜 發送紀錄 |
| 誰改了什麼、改錯了想還原 | 🕘 變更紀錄（管理員） |
| 換這個牧區的密碼 | ⚙️ 設定 → 這個牧區 → 牧區密碼（忘了找伺服器管理員） |
| 覺得怪怪的 | ❓ 說明 → 🩺 系統檢查 |
| 重開免費模式後網址變了 | 不用貼給任何人：請其他管理員在 LINE 打 `/服務網址`，機器人就會回最新的網址 |

### 三種發送方式，挑方便的用

| 情況 | 怎麼做 | 要不要錢（LINE 額度） | 要開著什麼 |
|---|---|---|---|
| **每週固定提醒** | 後台照每個牧區的時間自動發（上面第 7 步）；Telegram 可以當備援（第 8 步） | Push：按群組人數扣免費額度（每月 200 則，所有牧區共用） | 後台（`2-start`），或 Telegram 機器人 |
| **服事表改了，想馬上通知** | 在 Telegram 下指令呼叫 `cli.bat send`；或雙擊 `send-now.bat` | Push：同上；內容沒變的不會重送 | 不用 |
| **想免費讓群組看到、或讓大家登記 ID／名字** | 雙擊 **`3-open-webhook.bat`**（免費模式），在群組打 `/提醒`，用完關掉 | 免費（Reply） | 那個視窗開著的時候才有效 |

- **免費模式**會自己打開管理網頁、開臨時網址，並**自動登記到 LINE**，不用再手動貼 Webhook URL（第一次要先裝 cloudflared，
  並在 LINE Developers 打開一次「Use webhook」，見 [docs/SETUP_LINE.md](docs/SETUP_LINE.md) 第 5 步）。
  每次重開網址都會變，但不用貼給別人：管理員在 LINE 打 `/服務網址` 就會拿到現在的網址
  （進去還是要密碼，所以請先在「設定 → 金鑰與密碼」設一個密碼；沒設密碼時機器人只會回給管理員）。
- **Telegram 呼叫 `scripts\windows\cli.bat`**：不會問問題、不會等按鍵，跑完就結束。
  - `cli.bat send`：發送**今天輪到的牧區**（已經送過、內容沒變的自動略過；有人 2 天內打過 `/提醒` 也算送過）。
    `--牧區 青年牧區`（或 `-m m1`）只發那一個、不管是不是發送日；`--all` 每個牧區都發
  - `--retries 3 --retry-wait 300`：讀不到服事表、LINE 暫時連不上這種「等一下可能就好」的問題，每 5 分鐘再試、最多 3 次
    （設定錯、沒有群組、額度用完這種重試也沒用，就不等）；最多重試完約 15 分鐘才結束，Telegram 那邊請讓它在背景跑
  - `--popup`：最後還是失敗，就在這台電腦跳出小視窗通知（管理員的 LINE 通知也只發最後一次，不會每試一次就扣一則）
  - `cli.bat quota`：查本月 LINE 用量。排在 `send` 之後約 5 分鐘呼叫一次最準
    （LINE 自己的用量統計會延遲幾分鐘，發送當下問到的數字還沒算進這一次）；管理網頁開著的話它會自己更新，不用這個指令
  - `cli.bat preview`（只看不發）、`cli.bat check`（健康檢查），預設每個牧區都跑，一樣可以加 `--牧區`
  - `cli.bat 狀態`（或 `status`）：一個指令看**所有牧區**——服事表排到哪一天（剩幾天）、上一次發送是什麼時候／
    結果如何、下一次什麼時候發、本月 LINE 用量。`--telegram` 同時傳一份到手機、`--quick` 不連網讀服事表、
    `--short` 一個牧區一行
  - `cli.bat 牧區`：列出牧區；`cli.bat 牧區 add 名稱`、`rename 舊 新`、`temp-password 名稱`（給一組臨時密碼，預設 = 網站密碼，第一次進來要換）、`clear-password 名稱`（在這台電腦上清掉）
  - 結束代碼：0 = 正常、1 = 有要處理的事、2 = 設定有問題
- 同時從好幾個地方觸發也沒關係：有防重複＋跨程式的鎖，同一週同樣的內容只會發一次。
- 其他：`check.bat`（健康檢查＋預覽）。Mac 對應的是 `scripts/mac/*.sh`。

## 各種狀況，程式會怎麼處理

| 狀況 | 程式會怎樣 | 你要做什麼 |
|---|---|---|
| 服事表出現新名字、打錯字 | 照原樣送出，並提醒管理員（附上「可能是誰」） | 到「🙋 同工名單」一鍵處理 |
| 有人離開教會／不再服事 | — | 「🙋 同工名單」改成停用，以後被排到會提醒 |
| 服事表快用完 | 剩 14 天時提醒管理員 | 排下一期 |
| 這週服事表沒資料 | **不發送**，❌ 通知管理員 | 更新服事表後按「立刻發送」 |
| 機器人被踢出群組 | 通知管理員 | 重新邀請，或把群組停用 |
| LINE token 失效 | ❌ 通知管理員、主控台變紅 | 重新發行 token（見 SETUP_LINE） |
| LINE 本月額度用完 | ❌ 通知管理員 | 見 [docs/LINE_PRICING.md](docs/LINE_PRICING.md) |
| 電腦剛好關機錯過時間 | 12 小時內打開程式自動補發 | 建議設定開機自動執行 |
| 後台自己當掉、被關掉 | Telegram 收到「意外停止」；下次開起來那一則會說「上一次沒有正常關閉」 | 設定 Telegram（見下面），並把後台註冊成 Windows 服務 |
| 提醒順利送出去了 | 彙總（送了幾則、送到哪些群組）傳給管理員（LINE）和伺服器管理員（Telegram） | 不想多花 LINE 則數：「設定 → 發完之後的彙報」取消勾選 |
| 同一週按了兩次發送 | 第二次自動略過 | 真的要重發請按「重新發送」 |
| 服事表某一列日期寫錯 | 那一列跳過，主控台和「服事表」頁告訴你是第幾列 | 修正那一列 |

> ⚠️ 如果問題出在 LINE 本身（例如 token 失效），就沒辦法用 LINE 通知你了。這時問題只會顯示在管理網頁主控台和 `data/church_bot.log`，建議偶爾打開主控台看一眼。

## 檔案說明

| 檔案 | 是什麼 | 可以手動改嗎 |
|---|---|---|
| `config/church.yaml` | 牧區清單（編號、名稱、牧區密碼的雜湊）、網頁位址 | 建議用網頁改（首頁、牧區的「設定 → 這個牧區」） |
| `config/ministries/m1/settings.yaml` | 這個牧區的設定（每個牧區一個資料夾，m1、m2…） | 可以，但建議用網頁改 |
| `config/ministries/m1/targets.csv` | 這個牧區的 LINE 群組（含每個群組自己的提醒訊息） | 可以，用 Excel 開就能改 |
| `config/ministries/m1/members.csv` | 這個牧區的同工名單 | 可以，用 Excel 開就能改 |
| `config/ministries/m1/teams.csv` | 這個牧區的小團（服事表寫團名就列出成員） | 可以，用 Excel 開就能改 |
| `.env` | LINE 金鑰、網站密碼、管理者密碼、驗證器金鑰、Telegram 登入碼設定（**機密**，整個教會一份） | 建議用網頁改 |
| `data/church_bot.log` | 紀錄檔；出問題時把它傳給維護的人 | 不用 |
| `data/ministries/m1/church_bot.db` | 這個牧區的發送紀錄（防止重複發送）、收集到的 LINE 帳號 | 不用；刪掉會忘記送過什麼和還沒對應的 LINE 帳號 |
| `data/church_bot.db` | 整個教會共用：LINE 用量、對外網址、還沒分配的群組、**變更紀錄** | 不用；刪掉會忘記變更紀錄 |
| `config/_before_ministries/`、`config/_deleted/` | 升級前的舊檔、移除的牧區（都沒有真的刪掉） | 確認不需要了可以刪 |
| `data/ministries/m1/send.lock` | 發送時排隊用的鎖（避免兩個程式同時發） | 不用，也不用刪 |
| `tools/nssm.exe` | 把後台包成 Windows 服務的小工具，`service\install.bat` 自己下載的 | 不用；刪掉再跑一次 install.bat 就有 |
| `data/notify_outbox.jsonl` | Notifier_TB 沒開著時先存下來的通知，之後自動補送 | 不用；刪掉就是放棄那些還沒送出去的通知 |

> 🔒 `.env`、`settings.yaml`、`config/` 底下所有 CSV、`service-account.json`、`data/` 都設定成**不會上傳到 git**，範例檔（`*.example.*`）才會。

## 給工程師

- 技術：Python 3.11+、FastAPI + Jinja2（伺服器端畫面，無前端建置）、APScheduler、httpx、gspread、pydantic v2、SQLite。
- 指令（`PYTHONPATH=src`）：`python -m church_bot init | web | check | preview | send [--牧區 X] [--all] [--force] | quota | 牧區`
- 測試：`pip install -r requirements-dev.txt`，然後 `pytest`
- JSON API：管理網頁開著時看 <http://127.0.0.1:8787/docs>
- 架構、錯誤處理原則、**怎麼把 LINE／Google Sheet 換成別的服務**：[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
