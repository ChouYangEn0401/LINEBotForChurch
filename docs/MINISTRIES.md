# 多牧區（牧區 → 群組）

> 一個程式、一個 LINE 官方帳號，管很多個牧區。每個牧區裡面就是原本那一整套：
> 服事表、同工名單、小團、LINE 群組、設定、發送紀錄，**各自獨立**，互不影響。

## 畫面怎麼走

```
登入（網站密碼：大家共用的那一組）            右上角「管理員登入」→ 伺服器管理員（管理者密碼）
 └─ 首頁：所有牧區（每個牧區一列：現在的狀況、幾個群組、什麼時候發、上次發送）
     ├─ 青年牧區（要輸入青年牧區的牧區密碼；伺服器管理員不用）
     │   └─ 跟原本一模一樣的後台：主控台、服事表、同工名單、LINE 群組、發送紀錄、設定、系統檢查、變更紀錄
     │       └─ LINE 群組：每個群組可以有自己的提醒訊息（標題、結尾、整則改寫）
     ├─ 壯年牧區 …
     ├─ ＋ 新增牧區
     └─ 還沒分配的群組（機器人被邀進去了、還不知道是哪個牧區的）
```

- 牧區裡側欄最上面是「← 所有牧區」和牧區名稱。王小明要幫別的牧區建系統：回首頁、點那個牧區（或新增一個）就好。
- 新牧區是空的：服事表還沒接、沒有群組，**自動發送先關著**，不會亂發。主控台的「運作流程」會帶著一步一步做：
  接服事表 → 同工名單 → LINE 群組 → 打開自動發送。
- 管理員才需要的頁面（設定、系統檢查、變更紀錄、全教會設定）要按右上角「進階頁面」才出現在側欄。
  這只是把畫面收起來，不是權限；權限看右上角的身分（見下面「三種身分」）。

## 每個群組自己的提醒訊息

「LINE 群組」頁編輯一個群組 →「這個群組的提醒訊息」：

| 欄位 | 留空 | 例子 |
|---|---|---|
| 標題 | 用牧區設定的標題 | 🎸 敬拜團這週誰上場 |
| 結尾文字 | 用牧區設定的結尾 | 週六晚上 7 點練團，記得帶譜 |
| 整則訊息 | 用牧區設定的那一則 | 按「從設定頁複製一份來改」，再改成這一群要的樣子 |

### 整則訊息怎麼寫（不用懂程式）

直接打字；要放資料的地方點上面的按鈕插入【標籤】，右邊（抽屜裡是下面）馬上顯示群組會收到的那一則。預設的那一則長這樣：

```
📣 【標題】
📅 【日期】・【聚會】

▸ 【服事名單】

📝 【備註】

【結尾】
```

| 標籤 | 換成 |
|---|---|
| 【標題】【結尾】 | 設定（或這個群組）的標題、結尾文字 |
| 【日期】【星期】 | 10/11（週日）、週日 |
| 【聚會】【備註】 | 服事表上的聚會名稱、備註 |
| 【服事名單】 | 誰服事什麼，**一項一行**；那一行前後的字每行都有：「▸ 【服事名單】」→「▸ 司琴：小明」「▸ 音控：阿德」… |
| 【群組名稱】 | 收到這則的 LINE 群組 |

- 沒資料的標籤自動拿掉，連它前面的「・」一起；**整行都沒資料就整行拿掉**（例如那一週沒有備註，「📝 【備註】」那行就不見）。
- 打錯標籤（例如【標提】）存不進去，畫面會說可以用哪些。
- 預覽只是預覽，不會送出；實際送出時有對應 LINE 帳號的人會被 @。
- 以前用 `{{ title }}` 寫的舊模板照樣能用；用舊的預設的，會自動換成上面這一份（排出來的字一模一樣，不會因為換寫法多發一次）。

群組自己的訊息寫錯了，存檔時就會擋下來；萬一還是壞了（例如直接用 Excel 改），只有那個群組那次不發，其他群組照常。

## 什麼時候發

- **後台開著（2-start 或免費模式），每個牧區照自己的「星期幾、幾點、每幾週」自動發**（牧區的「設定 → 什麼時候發」）。
  程式記住每個牧區下一次的時間，時間到才醒來，不是每隔幾分鐘去看。
- 錯過了（電腦關機、睡眠）：12 小時內打開程式會補發；超過就不補，主控台會顯示。
- **Telegram 備援**：Telegram 機器人每週呼叫 `cli.bat send`，會發「今天輪到的牧區」
  （自動發送開著、今天是它的發送日、是發送週）。`--牧區 青年牧區` 只發那一個、不管是不是發送日；`--all` 全部。
- 後台和 Telegram 都觸發也只會發一次（防重複：同一個群組、同一場聚會、內容沒變就略過；跨程式的鎖）。
- 「自動發送」關掉的牧區：只有按「立刻發送」、有人在群組打 `/提醒`、或 Telegram 指定 `--牧區` 時才發。
  在 LINE 打 `/設定 自動發送=關`（放假暫停）也會讓 Telegram 不指定牧區的那一條略過它。

## LINE 群組、人、指令

- **一個 LINE 群組只屬於一個牧區**：看哪個牧區的「LINE 群組」清單裡有它。
- 機器人被邀進新群組：教會只有一個牧區就直接加進那個牧區（先不啟用）；不然放在首頁「還沒分配的群組」，
  選牧區分過去（也可以在牧區的「LINE 群組」頁直接按「加入」）。在那個群組裡登記的名字會一起交過去。
- 群組裡的指令（`/提醒`、`/設定`、`/別周測試`、`/權限`…）都只看那個群組所屬的牧區：
  用那個牧區的設定、名單，驗證碼和錯誤通知只給那個牧區的管理員。
- 私訊機器人：跟一個牧區有關（同工名單、或在那個牧區的群組講過話）就算那個牧區。
  `/設定`、`/別周測試` 看他是哪個牧區的管理員，好幾個就請他到那個牧區的群組裡打（不猜，避免改錯牧區）。
- 同一個人在兩個牧區服事：兩邊的同工名單各登記一次（名單跟著牧區走，牧區之間互相看不到）。

### 把機器人加進已經有人的群組：「/點名」

LINE 不讓一般的官方帳號查「群組裡有哪些人」，所以從服事表出發：

1. 「同工名單 → LINE 帳號」按「開放登記」。
2. 管理員在那個群組打 **`/點名`**（只有管理員能打，免費的回覆）。機器人列出服事表從今天起、**這個群組會提醒到**
   （照「只發這些服事／聚會」）而且還沒辦法 @ 到的人，並教他們打 `/我的名字 你在服事表上的名字`；
   也列出已經登記、等確認的人，和已經 @ 得到幾位。
3. 大家打 `/我的名字 王小明`——一步就好，不用先打 `/我的ID`（那一則訊息本身就帶著是誰打的）。
4. 管理員回「LINE 帳號」按「**名字對得上的 N 位全部對應**」（登記的名字剛好是名單上一位還沒有 LINE 帳號的人）；
   撞名、名單上沒有、那位已經有帳號的，照舊一個一個處理。擁有者決定：**登記後一律等管理員確認，不自動對應**。
5. 再打一次 `/點名` 看還剩誰。收集完記得「關閉登記」。

## 三種身分

右上角會寫你現在是哪一種。權限是伺服器檢查的，不是只把按鈕藏起來。

| 身分 | 怎麼進來 | 可以做什麼 |
|---|---|---|
| 訪客 | 網站密碼（`.env` 的 `UI_PASSWORD`，大家共用） | 看首頁、**新增牧區**（新增時一定要設那個牧區的密碼）。進任何一個牧區都要那個牧區的密碼 |
| 牧區管理員 | 某個牧區的牧區密碼（瀏覽器記 30 天） | 只管那一個牧區：設定、群組、名單、訊息、改那個牧區的密碼、看它的變更紀錄 |
| 伺服器管理員（server_manager） | 右上角「管理員登入」：管理者密碼（`SERVER_MANAGER_PASSWORD`） | **所有牧區都進得去，牧區密碼對他無效**；全教會設定（LINE 金鑰、網站密碼）、替任何牧區設定或清掉密碼、移除牧區、還沒分配的群組、教會那一層的變更紀錄、**重新啟動** |

- **每個牧區都要有牧區密碼**：網站密碼是大家共用的，沒有牧區密碼的牧區等於誰都能改。還沒設的牧區（例如從舊版搬家來的）只有伺服器管理員進得去。
- **臨時密碼**：伺服器管理員在「全教會設定 → 牧區密碼」按「設臨時密碼」（留空 = 用網站密碼，不是管理者密碼），
  或 `cli.bat 牧區 temp-password 名稱`。牧區的人第一次用它進來，**一定要先換成只有他們知道的**才能用。
- 牧區密碼不能跟網站密碼、管理者密碼一樣；清掉牧區密碼只有伺服器管理員可以（牧區管理員清掉會把自己鎖在外面）。
- 牧區密碼忘了：請伺服器管理員再給一組臨時密碼；也可以在那台電腦上執行 `cli.bat 牧區 clear-password 名稱`。
- 牧區密碼只存 PBKDF2 雜湊，變更紀錄裡也遮掉。換牧區密碼，大家都要重新輸入。
- 防君子不防小人：網站密碼不小心外流，別的牧區的人也進不去上了鎖的牧區；真的改錯了還有變更紀錄可以還原。

### 伺服器管理員怎麼登入（照 CloudServicesPlatform 的做法）

| 從哪裡 | 要什麼 |
|---|---|
| 執行機器人的那台電腦上（本機） | 管理者密碼就好（坐在電腦前面是最後一道退路，手機不在身邊也進得去） |
| 從外面（免費模式的臨時網址） | 管理者密碼 **加上** 下面任一個：驗證器 App（Google Authenticator 這類）的 6 位數，或「傳 6 位數到我的 Telegram」 |

- 第一次設定：還沒設管理者密碼時，**坐在那台電腦前面的人就是伺服器管理員**。到「全教會設定 → 伺服器管理員」：
  設管理者密碼（至少 10 個字、不能跟網站密碼一樣）；設驗證器 App（掃 QR code，輸入 App 上的 6 位數確認才存）；
  或填 Telegram 機器人 token（跟排程用的同一個就可以）和你的 Telegram ID，按「傳測試訊息」。
- 這一張卡片**只能在那台電腦上改**：從外面借到管理者身分的人換不掉鑰匙。
- Telegram 的碼 90 秒內有效、只能用一次、錯 3 次作廢；另一半留在發起登入的那一頁，攔截到碼的人在別的瀏覽器按不進來。
- 從外面 15 分鐘內錯 5 次，就暫停外面的管理者登入 15 分鐘；本機不受影響。
- 管理者登入 12 小時後要重新登入；換管理者密碼，所有地方的管理者都要重新登入。

## 重新啟動

伺服器管理員右上角有「重新啟動」：更新過程式、或覺得怪怪的時候按一下，大約 5 秒就換成新的程序，
畫面會自己回到剛剛那一頁。不用再去關黑色視窗、重新雙擊 2-start。

- 有牧區正在發送提醒時會先擋下來，等它送完再按；排程時間到了剛好在重開也不會漏（開起來會補發）。
- 做法：2-start（還有免費模式、開機自動執行）開的是一個很小的外層程式，真正的網頁是它開的子程式；
  按「重新啟動」子程式就結束，外層再開一個新的，所以會載入新的程式碼。一分鐘內重開超過 5 次就停下來。

## 變更紀錄

- 每次存設定、LINE 群組、同工名單、小團、牧區清單，都記下**什麼時候、從哪裡**（管理網頁、LINE、LINE /設定、
  機器人、指令列、還原）、**改了什麼**（例如「新增「敬拜團」」「什麼時候發 › time：20:00 → 21:00」）。
  **不記是誰改的**（擁有者決定）。
- 有人直接用 Excel／記事本改檔案：下次程式存檔前會發現，補一筆「直接改檔案」，那次修改一樣看得到、還原得回來。
- 牧區裡「管理員 → 變更紀錄」：點一列看改了哪幾行，「還原成這次修改之前」；教會這一層的「變更紀錄」是牧區清單。
- 做法跟 git 一樣：每個版本用內容的 SHA-256 當名字、壓縮存一份，相同內容只存一份；一年大概幾 MB，不用清。

## 資料放哪裡

```
config/
  church.yaml                 牧區清單（編號、名稱、備註、牧區密碼的雜湊）＋ 網頁位址
  ministries/m1/              一個牧區一個資料夾，裡面的檔案跟以前 config/ 底下一樣
    settings.yaml  targets.csv  members.csv  teams.csv  （服事表 CSV 也可以放這裡，設定只寫檔名）
  _before_ministries/         升級前的舊檔（搬家時留一份，確認沒問題可以刪）
  _deleted/                   移除的牧區（整個資料夾搬過來，沒有真的刪）
data/
  church_bot.db               全教會共用：LINE 用量、對外網址、還沒分配的群組、變更紀錄
  ministries/m1/church_bot.db 這個牧區的發送紀錄、防重複、在它的群組裡收集到的 LINE 帳號
```

- **牧區編號（m1、m2…）建立後永遠不變**，網址（`/m/m1/`）、指令列都可以用它；名稱隨時可以改。
- LINE 金鑰、網站密碼只在 `.env`（整個教會共用一個 LINE 官方帳號，每月額度也共用，首頁看得到）。

## 決策

| 決策 | 原因 |
|---|---|
| 兩層（牧區 → 群組），不做無限層 | 每個牧區自己就是完整的一套，要多少就加多少；不用想「哪一層的設定生效」，不懂程式的人也看得懂。真的要再分層，牧區資料夾不用改 |
| 每個牧區一個資料夾，不合併成一份 | 乾淨：搬移、備份、刪除一個牧區就是一個資料夾；一個牧區的檔案壞掉不影響別人；原本的程式幾乎不用改，只是換資料夾 |
| 群組歸哪個牧區看 `targets.csv` | 跟以前一樣在「LINE 群組」頁管理；機器人新加入、還沒分配的群組先放在首頁 |
| 自動發送由後台內建排程，每個牧區一個鬧鐘 | 後台開著就照每個牧區自己的時間發；不是輪詢。Telegram 保留當備援 |
| `cli.bat send` 不帶牧區 = 今天輪到的牧區 | 現在 Telegram 週四那一條不用改；以後別的牧區設週六，Telegram 週六再呼叫一次就好 |
| 新牧區自動發送先關著 | 服事表、群組都還沒設好，不會亂發 |
| 群組自己的模板壞了只停那個群組 | 一個群組寫錯不該讓整個牧區都收不到提醒 |
| 三種身分：訪客、牧區管理員、伺服器管理員 | 擁有者要「網站密碼進來的人有一點點權限（看首頁、建牧區），進牧區要那個牧區的密碼，伺服器管理員什麼都能管」 |
| 新增牧區一定要設牧區密碼 | 建的人之後進得來，沒有密碼的人進不去；建的人的瀏覽器直接記住，不用馬上再輸入 |
| 伺服器管理員：本機只要密碼，外面要再加驗證器或 Telegram | 照 CSP：本機是最後一道退路；外面多一道，管理者密碼外流也進不來 |
| 管理者密碼、第二道驗證只能在本機改 | 從外面借到管理者身分的人換不掉鑰匙 |
| 重新啟動用外層程式重開子程式 | 要載入新的程式碼就一定要新的程序；同一個程序裡重跑網頁伺服器沒有用 |
| 罐頭訊息用【中文標籤】 | 不懂程式的人也看得懂、改得動；舊的 Jinja2 寫法保留給已經改過的人 |
| 變更紀錄內建，不用 git、不用 DoltLite | DoltLite 沒有 Windows 版、Python 套件還是 Alpha、要把 CSV 改成資料庫（Excel 就不能改了）；git 要每台電腦都裝、非工程師看不懂。借它們「內容定址、相同內容只存一份」的做法 |
| 不記是誰改的 | 擁有者決定：只記時間、來源和內容 |
| 移除牧區不刪資料 | 資料夾搬到 `config/_deleted/`，發送紀錄、變更紀錄都留著，搬回來就復原 |
| 拿掉「大教會（實驗）」頁 | 它只是估算，已經被正式的牧區取代；費用估算看首頁的 LINE 額度和 docs/LINE_PRICING.md |

## 從單一牧區升級

第一次用新版開啟時（管理網頁、`cli.bat` 都會）自動搬家：原本 `config/` 的設定與三張表搬進
`config/ministries/m1/`，資料庫複製一份給它（發送紀錄、防重複、收集到的 LINE 帳號都跟著走），
原檔另外留一份在 `config/_before_ministries/`、`data/_before_ministries/`。
牧區名稱先叫「第一個牧區」，到「設定 → 這個牧區」改名（或 `cli.bat 牧區 rename m1 青年牧區`）。
網頁的 host/port 搬到 `church.yaml`。**自動發送會被打開**：舊版關著通常代表「由 Telegram 發」，
新版 `cli.bat send` 不帶牧區只發自動發送開著的牧區，不打開 Telegram 那一條就什麼都不發；
打開之後後台開著也會照時間發，兩邊都觸發也只發一次。什麼都不用重新設定，Telegram 的排程也不用改。

搬家後的「第一個牧區」還沒有牧區密碼，所以只有伺服器管理員進得去。上線時照這個順序做一次（在那台電腦上）：
1. 首頁右上角「進階頁面」→「全教會設定 → 伺服器管理員」設管理者密碼（之後想從外面登入，再設驗證器 App 或 Telegram）。
2. 點進「第一個牧區」→「設定 → 這個牧區」改名成「青年牧區」；到「全教會設定 → 牧區密碼」按「設臨時密碼」
   （留空 = 網站密碼），告訴王小明、林美華：第一次進來會被要求換成你們自己的。
3. 網站密碼（`.env` 的 `UI_PASSWORD`）照舊是大家共用的那一組。

## 之後可以做的（還沒做）

- **每個人一個帳號**（例如 LINE Login）：現在是共用的網站密碼＋每個牧區一組密碼＋伺服器管理員，變更紀錄也就記不到「是誰」。
- **用量按牧區分開統計**：額度是整個 LINE 官方帳號共用；要各牧區分開報帳，可以依發送紀錄算每個牧區用掉幾則，
  或每個牧區一個官方帳號（所有 Channel 建在同一個 Provider 底下，LINE userId 才會一樣）。
- **同名同姓**：同工名單以名字為鍵；牧區分開之後同一個牧區裡同名同姓才會撞到，真的遇到再改成內部編號。
- **只私訊當週有服事的人**：省額度最多的一步，代價是每個人都要加機器人好友、Webhook 要一直開著。
- **主機**：要一直收集名字、很多牧區同時用，最好 24 小時開著、有固定的 https 網址（雲端主機或固定的 Cloudflare Tunnel）。
