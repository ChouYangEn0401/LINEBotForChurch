# 從零開始：申請帳號 + 安全測試（新手向）

給第一次做這件事的人：一步一步，從什麼都沒有，做到「機器人傳一則訊息到你自己的手機」。
全程**只有你自己會收到測試訊息**，不會驚動教會的任何一個群組，可以放心亂試。

> 這篇著重在「安全地测试」。設定細節、每個畫面的完整選項說明在 [SETUP_LINE.md](SETUP_LINE.md)、
> [SETUP_GOOGLE.md](SETUP_GOOGLE.md)；原理（Provider、Webhook 是什麼、為什麼）在
> [LINE_IDS_AND_MEMBERS.md](LINE_IDS_AND_MEMBERS.md)。卡關時可以回去查。

**全程不用花錢**，大約 30～40 分鐘。

---

## 開始之前：5 個名詞先看過一次

不用背，先有印象，卡關的時候回來對照就好。

| 名詞 | 白話意思 |
|---|---|
| **LINE 官方帳號** | 你要建立的那個「機器人」的身分，別人在 LINE 上看到的名字就是它 |
| **Provider（服務提供者）** | 一個大戶頭，底下放你的機器人。這個專案只需要建立**一個**，建好之後不要刪掉重建（詳見 [LINE_IDS_AND_MEMBERS.md 第 2 節](LINE_IDS_AND_MEMBERS.md#2-line-developers-裡的provider是什麼)） |
| **Channel access token** | 機器人的「鑰匙」，程式要靠這個才能用機器人的身分發訊息。這是唯一一定要拿到的東西 |
| **Push（發送）** | 機器人**主動**把訊息送出去，例如每週提醒。**不需要**任何公開網址，你的電腦開著、能上網就好 |
| **Webhook** | LINE **主動通知**你的程式「有人做了什麼事」（例如打字）。這才需要一個公開網址，但只有**抓 ID 的那幾分鐘**需要暫時開一下，平常不用（詳見 [LINE_IDS_AND_MEMBERS.md 第 1 節](LINE_IDS_AND_MEMBERS.md#1-先搞懂機器人和-line-之間有兩個方向只有一個方向需要伺服器)） |

**這份教學的原則：先讓機器人只找得到「你自己」，確定一切正常，最後一步才接觸教會真正的群組。**

---

## 第 0 階段：準備

- [ ] 一個你平常在用的 LINE 帳號（手機要有安裝 LINE，且是**手機版**登入過，不是只用電腦版——原因見 [LINE_IDS_AND_MEMBERS.md](LINE_IDS_AND_MEMBERS.md#3-三種-id)）
- [ ] 一個 Email
- [ ] 這台電腦已經照 [README](../README.md) 的「安裝」步驟裝好（`1-install`）

---

## 第 1 階段：不碰 LINE，先確定程式本身會動

在申請任何帳號之前，先確定「大腦」是好的——這樣之後如果哪裡出錯，你會知道問題出在 LINE 那邊，而不是程式本身。

1. 打開管理網頁（雙擊 `2-start`）。
2. 主控台會直接用**內建的範例服事表**顯示這週的提醒訊息長什麼樣子——這時候還沒有連真的 LINE，是正常的。
3. 到「⚙️ 設定 → 發送行為 → 發送方式」（先按右上角「切換身分」切到管理員，側欄才有「設定」），確認是「**測試模式**」（預設就是，不用改）。
4. 到「👥 LINE 群組」新增一筆：名稱隨便打（例如「測試」），LINE_ID **先留空**、啟用打勾 → 儲存。
5. 回主控台，按「這次會發送」右邊的「**立刻發送**」。
6. 打開資料夾裡的 `data/outbox.log`，應該會看到剛剛那則訊息被寫進去。

✅ **看到這個檔案有內容，代表程式本身完全正常**，接下來的步驟只是把「測試模式」換成「真的 LINE」而已。
（第 4 步新增的這筆等一下會刪掉或改掉，不影響後面。）

---

## 第 2 階段：申請 LINE 機器人，拿到 token

1. 打開 <https://manager.line.biz/>，用你的 LINE 帳號登入 → 「建立 LINE 官方帳號」→ 帳號名稱隨便取（之後可以改，例如先取「測試機器人」）。
2. 進去之後：「設定」→「Messaging API」→「啟用 Messaging API」→ 第一次會請你選 Provider → 選「**建立新的服務提供者**」，名稱填教會名稱（這就是上面說的「大戶頭」，建一次就好）。
3. 打開 <https://developers.line.biz/console/>（同一個 LINE 帳號登入）→ 找到剛剛的 Provider → 點進你的官方帳號 → 切到「**Messaging API**」分頁 → 拉到最下面「Channel access token」→ 按「**Issue**」→ 複製那一長串文字。

    > 這串文字很長很亂是正常的，直接整串複製，不要漏字。

4. 回到管理網頁「⚙️ 設定 → 金鑰與密碼」，貼到「Channel access token」→ 儲存。
5. 到「⚙️ 設定 → 發送行為 → 發送方式」（先按右上角「切換身分」切到管理員，側欄才有「設定」），改成「**LINE（正式發送）**」→ 儲存。
6. 打開「❓ 說明 → 🩺 系統檢查」，「LINE 連線」那一列應該變成 ✅，並顯示你機器人的名字。

✅ **看到機器人名字，代表 token 是對的**，機器人已經可以說話了，只是還沒有人加它好友。

> 💰 這一步完全免費。免費方案每月可以發 200 則，見 [LINE_PRICING.md](LINE_PRICING.md)。

## 第 3 階段：先只測試「你自己」（最關鍵的安全測試）

**先不要邀進任何群組**，用一個小技巧，讓機器人只找得到你一個人：

1. 用手機 LINE 掃描 LINE Developers「Messaging API」分頁上的 QR code，**加機器人好友**。
2. 對它私訊打 **`/我的ID`**，它會回你一串 `U` 開頭、很長的英數字——這就是你自己的 userId，複製起來。
3. 回到管理網頁「👥 LINE 群組」，**編輯剛剛第 1 階段新增的那一筆**（或新增一筆新的）：
   - 名稱：改成「我自己」
   - LINE_ID：貼上剛剛複製的 `U……`（沒錯，這格雖然叫 LINE_ID，個人的 userId 也能填）
   - 啟用：打勾 → 儲存
4. 按這一列的「**測試**」按鈕。
5. 打開你的手機 LINE，應該會收到一則測試訊息。

✅ **收到訊息，代表「申請 → 設定 → 發送」整條路都是通的**，而且全程只有你自己知道，教會的同工完全不會看到任何動靜。

如果想順便測試「@ 標記」功能：把這筆的「@ 標記服事的人」打勾，回主控台按「立刻發送」，看看範例服事表裡對應到你名字的地方會不會被 @ 到（要先在「🙋 同工名單」把你的名字設定成有這個 userId）。

---

## 第 4 階段：小範圍測試群組（找 1～2 位熟悉的同工）

確定第 3 階段沒問題後，再往前一步，但還是不要動教會正式的服事群組：

1. 手機 LINE 建一個新群組，只拉 1～2 位你信任、知道這是在測試的同工進來。
2. 把機器人也邀進這個測試群組。
3. 在群組裡打 **`/群組ID`**，機器人會回覆一串 `C` 開頭的 ID（如果沒反應，代表還沒開 Webhook，做法在 [SETUP_LINE.md 第 5 步](SETUP_LINE.md#5-把機器人加進群組拿到群組-id)，抓完 ID 就可以關掉，不用一直開著）。
4. 「👥 LINE 群組」新增一筆，名稱寫「測試群組」，貼上這個 `C……` ID → 儲存 → 按「測試」。
5. 群組裡的每個人都應該收到測試訊息。

✅ 到這裡，「機器人送到群組」「群組人數怎麼算」「LINE 額度怎麼扣」你都已經亲眼確認過一遍。

---

## 第 5 階段：正式上線

只有前面四個階段都順利，才進行這一步——這是唯一會影響教會正式群組、正式服事表的階段：

1. 把「我自己」「測試群組」這兩筆測試用的資料從「👥 LINE 群組」刪掉（或關掉啟用）。
2. 接上真的 Google Sheet 服事表：[SETUP_GOOGLE.md](SETUP_GOOGLE.md)。
3. 把機器人邀進教會真正的服事群組，重複第 4 階段的方式拿到群組 ID，新增到「👥 LINE 群組」。
4. 私訊機器人「/我的ID」，把你自己的 ID 填到「⚙️ 設定 → 出問題通知誰」（先按右上角「切換身分」切到管理員，側欄才有「設定」）（這樣以後出狀況才找得到你）。
5. 打開「❓ 說明 → 🩺 系統檢查」，全部 ✅。
6. 設定開機自動執行（`autostart-on`），這樣就不用每次都手動開著程式。
7. 到 [docs/HANDOVER.md](HANDOVER.md) 的「上線檢查清單」再核對一次。

🎉 完成！之後只要照常更新 Google Sheet，其他什麼都不用做。
