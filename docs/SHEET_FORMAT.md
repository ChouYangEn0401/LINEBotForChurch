# 服事表怎麼排

程式讀得很寬鬆，**大部分現有的服事表不用改就能讀**。
這份說明給「想確定不會出錯」或「讀不到時要怎麼改」的人看。

---

## 三種排法（設定選「自動判斷」就好）

### ① 日期在左，一列一次聚會（最常見，最推薦）

| 日期 | 聚會 | 講員 | 司會 | 敬拜主領 | 司琴 | 音控 | 招待 | 備註 |
|---|---|---|---|---|---|---|---|---|
| 2026/9/13 | 主日崇拜 | 王牧師 | 恩典 | 小明 | 美華 | 阿豪 | 喜樂、恩典 | 聖餐主日 |
| 2026/9/20 | 主日崇拜 | 李傳道 | 喜樂 | 美華 | 小明 | 阿豪 | 建國、心怡 | |

- 要有一欄「**日期**」（寫「主日」「Date」也可以）。
- 「**聚會**」「**備註**」兩欄是選用的；**其他每一欄都當成一項服事**，欄位名稱就是訊息上的服事名稱。
- 表頭上面有標題列（例如「2026 第四季服事表」）沒關係，程式會自動往下找表頭。

### ② 一列一項服事

| 日期 | 服事項目 | 人員 |
|---|---|---|
| 9/13 | 講員 | 王牧師 |
| | 司琴 | 美華 |
| | 招待 | 喜樂、恩典 |
| 9/20 | 講員 | 李傳道 |

- 需要「**日期**」「**服事項目**」「**人員**」三欄（寫「服事」「職務」「同工」「姓名」也認得）。
- 跟上一列同一天，日期可以留空或用合併儲存格。

### ③ 日期在上，一欄一次聚會

| 服事 | 9/13 | 9/20 | 9/27 |
|---|---|---|---|
| 講員 | 王牧師 | 李傳道 | 王牧師 |
| 司琴 | 美華 | 小明 | 美華 |
| 備註 | 聖餐 | | 宣教主日 |

- 第一列放日期，第一欄放服事項目。
- 名稱是「備註」「聚會」的那一列，會變成當天的備註／聚會名稱。

## 格子裡怎麼寫

| 情況 | 寫法 | 例子 |
|---|---|---|
| 一格多人 | 用 `、` `,` `/` `;` `+` `&` 或換行隔開 | `喜樂、恩典` |
| 中文名字用空白隔開 | 也可以 | `小明 美華` |
| 英文名字 | 空白不會被拆開 | `John Chen` |
| 沒有人 | 留空，或寫 `-` `無` `休` `暫停` `X` `N/A` `/` | `-` |
| 加註記 | 用括號；括號裡的逗號不會被拆開 | `小明(代)`、`美華（主領、吉他）` |
| 綽號 | 直接寫，到「🙋 同工名單」設定對應到誰 | `阿豪` → 張志豪 |

## 日期寫法

以下都可以：`2026/9/13`、`2026-09-13`、`2026年9月13日`、`115/9/13`（民國）、`9/13`、`9月13日`、`9/13（日）`、`9/13 聖餐主日`、`Sep 13`

- **沒寫年份**：自動挑離今天最近的那一年（12 月排隔年 1 月的表也不會錯）。
- **日期是合併儲存格**：會自動沿用上一個日期。
- 夾在中間的分隔列（例如只寫「十月」、其他格子空白）會自動略過。

## 一天有兩場聚會

加一欄「聚會」，同一個日期寫兩列：

| 日期 | 聚會 | 講員 | 司琴 |
|---|---|---|---|
| 9/13 | 第一堂 | 王牧師 | 美華 |
| 9/13 | 青年崇拜 | 李傳道 | 小明 |

會分成兩則提醒。在「👥 LINE 群組」可以設定某個群組**只收某一場**（例如青年群組的「只發這些聚會」填「青年」）。

## 不想出現在提醒裡的欄位

例如「經文」「詩歌」「星期」：到「⚙️ 設定 → ① → 不要放進提醒的欄位」填進去。

---

## 讀不到的時候

首頁和「❓ 說明 → 🩺 系統檢查」會告訴你哪裡看不懂，例如「服事表第 12 列的日期看不懂：『某天』，這一列先跳過」。

最常見的原因：

1. 表頭沒有「日期」這一欄 → 把日期那一欄的標題改成「日期」。
2. 日期欄寫了文字 → 改成 `9/13` 這種格式。
3. 分頁選錯 → 網址最後的 `#gid=數字` 決定是哪個分頁，重新點開正確的分頁再複製網址。
4. **兩列式的表頭**（第一列是合併儲存格「敬拜」，第二列才是「主領／司琴」）→ 請改成一列：「敬拜主領」「敬拜司琴」。
